# MCP

MCP is **Live** as Conductor Relay's public tool interface. Before calling a
tool, check the live [MCP documentation](https://www.conductorrelay.com/mcp)
and [capability directory](https://www.conductorrelay.com/.well-known/capabilities.json).

The live documentation and tools are authoritative for current availability,
authorisation, and usage. This page is explanatory only; it does not prescribe
commands or duplicate a tool inventory.
