# Coordination workspace

This directory holds the lightweight coordination record for a project using
multiple coding agents. It is deliberately tool-neutral: Codex, Claude, and
human contributors follow the same lane and handoff rules.

Start each scoped task by reading [LANES.md](LANES.md). Claim the paths you
intend to change before editing them. When work changes hands, use
[HANDOFFS.md](HANDOFFS.md) and the templates in [templates](templates/).

These files coordinate work in this repository; they do not grant deployment,
publication, or operator authority.
